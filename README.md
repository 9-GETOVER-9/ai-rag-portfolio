## 一句话介绍

这是一个个人作品集网站，用一个可浏览的页面介绍 AI / RAG 项目与相关技术实践。

<a id="section-2"></a>

## 在线体验

[打开作品集](https://9-getover-9.github.io/ai-rag-portfolio/)

<a id="section-3"></a>

## 快速开始

```bash
git clone https://github.com/9-GETOVER-9/ai-rag-portfolio.git
cd ai-rag-portfolio
npm install
npm run dev
```

<a id="section-4"></a>

## 功能矩阵

| 功能 | 说明 |
|---|---|
| 个人介绍 | 呈现项目定位与背景 |
| 项目展示 | 集中浏览 AI / RAG 相关实践 |
| 响应式页面 | 适配桌面和移动端阅读 |
| 构建与发布 | 提供 Vite 构建及 GitHub Pages 部署脚本 |

## 核心工作流

```text
浏览首页 → 了解技术方向 → 查看项目 → 联系作者
```

<a id="section-6"></a>

## 项目结构

| 路径 | 用途 |
|---|---|
| `src/` | 页面与组件源码 |
| `src/assets/` | 页面使用的静态资源 |
| `package.json` | 开发、测试与部署命令 |

<a id="section-7"></a>

## 验证与部署

运行 `npm test`、`npm run lint`、`npm run build` 进行验证；`npm run deploy` 发布到 `gh-pages` 分支。
